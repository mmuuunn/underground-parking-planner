# 지하주차 계획모델

이 폴더는 새 지하주차 계획모델의 중립적인 작업공간이다.

- `candidates/`: 특정 배치 형식의 후보 생성기. 현 v0.4 정형 순환형은 이곳에 보존한다.
- `evaluators/`: 생성 결과와 독립된 기하·차량·구조·보행·법규 판정.
- `route-types/`: 순환형·중앙 주통로형·가지형+회차형·한쪽 반환형·복수구역형의 동선 골격.
- `planning/`: 여러 후보와 판정을 조합하고 대안을 비교하는 상위 계획모델.

새 구현은 42차 모델 크리틱과 43차 재인계서의 승인을 따른다. 입력·출력·합격조건과 골든케이스가 없는 상태에서 코드를 먼저 추가하지 않는다.
