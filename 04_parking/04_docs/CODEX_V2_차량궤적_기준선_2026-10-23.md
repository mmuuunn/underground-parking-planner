# V2 차량 궤적 기준선

## 이번에 고정한 구조

- `CODEX_rsplan_reference.py`: 외부 `rsplan 1.0.10`의 Reeds–Shepp 결과를 비교 기준으로 출력한다.
- `CODEX_vehicle_swept_path.js`: 차량의 뒤축 중심 궤적을 실제 차체 사각형으로 펼쳐 외곽·코어 충돌을 판정한다.
- `CODEX_vehicle_route_candidates.js`: 최단거리보다 통과 여부를 먼저 보고, 통과 후보 안에서 방향 전환 수와 길이로 순위를 정한다.

외부 라이브러리는 MIT 라이선스이며 제품 코드에 복사하거나 런타임 의존성으로 넣지 않았다. 기준답안을 생성하는 연구 도구로만 사용한다.

## 중요한 구분

- 법규 또는 설계기준의 `램프 안쪽 회전반경`
- 차량 모델의 `뒤축 중심 궤적 최소 회전반경`

두 값은 같은 값이 아니다. V2 계약에서도 별도 필드로 유지해야 한다.

현재 차량 기본값은 법정 확정값이 아니라 시험용 승용차 모델이다. 폭 1.9m, 축거 2.8m, 앞·뒤 오버행 각 0.95m, 추가 여유 0.25m를 쓴다.

## 현재 검증 범위

- 직선 주행
- 90도 회전
- 중앙 코어와의 충돌 검출
- 코어를 피하는 복수 후보 중 통과 가능한 경로 선택
- 외곽 이탈과 장애물 충돌의 구분

13개 V2 시험이 통과한다. 아직 `PASS`는 차량 외곽의 기하 충돌 판정만 뜻하며, 법규·경사·시야·기둥·연석 판정까지 통과했다는 뜻은 아니다.

## 다음 구현 순서

1. 차로 그래프의 교차점과 끝점을 차량 경로 시작·종료 자세로 변환한다.
2. 직선·90도·유턴 연결 후보를 만들고 차량 외곽 판정기로 탈락시킨다.
3. 통과한 차량 경로가 없는 차로 후보는 주차면 수와 무관하게 폐기한다.
4. 차량 종류별 모델과 설계 여유를 입력 계약으로 분리한다.
