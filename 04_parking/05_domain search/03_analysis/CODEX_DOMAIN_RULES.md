## 3. 수치 충돌을 다루는 방법

| 항목 | 확인된 변동 | 데이터 처리 |
|---|---|---|
| 확장형 | 30% → 40% → 50% | `project.requirements.wide`에 근거·적용일과 함께 저장 |
| 경형 | 10% 이하 → 5% 이하 → 3% 이하 | 최대치이므로 계획 목표와 법정/발주 한도를 분리 |
| 장애인 | 3% 또는 4% | 시설 전체 요구량과 층별 배분을 분리 |
| 구조 | LH형 무량판 / 라멘 또는 무량판 | 프로젝트 입력 없이는 구조 형식 `unknown` |
| 공통 LH 지침 | 어떤 문서에서는 붙임·반영, 어떤 문서에서는 참고 | 파일 제목이나 최신 연도만으로 의무 여부를 정하지 않음 |

## 4. 자동 판정에 아직 쓰지 않을 항목

기둥 스팬·단면, 방화구획, 피난거리, 제연·배연, 환기량, 배수용량, EV 화재 안전, 차량 회전 궤적은 이번 자료만으로 PASS/FAIL 수치를 만들 수 없다. 데이터 객체와 `UNVERIFIED` 상태만 준비한다.
