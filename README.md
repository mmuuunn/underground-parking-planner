# 지하주차 기본계획 도구

현상설계 공모 초기 단계에서 주차 배치, 램프, 차량 순환 가능성을 비교하기 위한 개발 프로젝트입니다.

현재 단계는 **차량 순환 검증**입니다. 결과는 설계 검토를 돕는 초안이며, 인허가·구조·소방·접근성 적합성을 최종 보증하지 않습니다.

## 현재 실행 화면

`04_parking/underground-compare.html`

## 기준 검증

저장소 루트에서 다음 명령을 실행합니다.

```powershell
npm test
```

이관 기준점은 지정된 5개 테스트 파일의 **57개 테스트 통과**입니다.

## 작업 방식

개발을 시작하기 전에 `tools/harness/README.md`, `tools/harness/policy.yaml`, 현재 stage와 work item을 확인합니다. 제품 방향과 화면 결과는 사용자가 최종 승인하고, 작업 범위·검증·단계 운영은 Codex가 담당합니다.

과거 실험, 대량 조사 원문, 에이전트 로그와 이전 Git 이력은 별도 보존되어 있으며 이 저장소에는 현재 제품에 필요한 자료만 둡니다.
