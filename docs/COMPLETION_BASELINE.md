# 지하주차 기본계획 도구: 완성 기준과 현재 상태

작성: 2026-10-28. 제품 방향과 화면 결과는 사용자 확인을 거친다. 이 문서는 제안 및 점검 기준이며 법규의 확정 해석이나 완료 판정이 아니다. 기존 골든값과 안전 판정은 유지한다.

## 목표

현상설계 공모 초기 단계에서 지하 외곽과 구조·코어·램프 조건에 따른 주차 배치, 대수, 램프 형식과 차량 동선을 비교한다. 인허가 도서나 구조·소방·보행 적합성을 보증하는 도구는 아니다. 10월 31일까지의 범위와 달성 가능성은 아래 미완료 항목의 작업량 확인 후 판단한다.

## 하네스 개선 순서

1. **기준과 증거 연결:** 각 작업에 목표, 비교 조건, 성공·실패 사례, 측정 결과, 미검증, 사용자 확인 상태를 명시한다. 공통 시험 통과와 작업 합격을 별도로 기록한다.
2. **상태 기록의 무결성:** UG-LAYOUT-002의 사용자 검토 제목과 UG-LAYOUT-003의 구현 제목이 앞 문장에 붙은 기록을 정리하고, 87대 안에 대한 후속 사용자 의견을 반영한다. 실제 상태가 바뀌기 전 완료로 쓰지 않는다.
3. **범위와 진행 제어:** 작업의 적절한 점검 시점과 중단 기준을 정해 목표 대비 진척·장애·다음 실험을 기록한다. 목표에 기여하지 못하는 반복은 중단하고 구조를 재검토하며, 실질 개선이 없으면 성공으로 처리하지 않는다. 이전에 제안된 30분·3시간은 이 단계에 적합한지 검토할 수치이며 고정 기준이 아니다.
4. **기계 판정의 범위 명확화:** 현재 preflight는 작업 시작 조건과 파일 존재를 확인하고 한도를 기록한다. verify는 공통 시험 결과를 기록한다. 허용 파일 변경, 작업별 합격 조건, 독립 검토 및 사용자 확인은 이 결과만으로 자동 보장되지 않으므로 별도로 확인한다.
5. **도구 적용:** 기존 시험을 우선 사용한다. Promptfoo는 구조화된 예시에서 조건부를 합격으로 잘못 표시하는 규칙을 탐지하는 소규모 실험만 수행했다. 자연어 판단·실제 에이전트 평가를 입증하지 않았으므로 필수 의존성으로 추가하지 않는다.

## 다음 작업의 반례와 통과 사례

- 실패 F1: 막다른 가지의 주차칸이나 회차가 미검증인데 정상 주행 또는 계획 합격이라고 표시한다.
- 실패 F2: 주차 대수만 증가하고 동선과 잔여공간이 실질적으로 개선되지 않았는데 개선으로 확정한다.
- 실패 F3: 후보가 기존 기둥·코어·램프 조건을 바꾸거나 충돌을 만들었는데 같은 조건의 안전한 대안으로 표시한다.
- 통과 P1: 동일 조건의 연결된 순환 대안을 제시하고 검사 범위·문제·변경 전후를 함께 보고한다. 실제 주행이나 법규의 미검증 사항은 남긴다.
- 통과 P2: 대안을 찾지 못한 경우 조사 범위와 실패 원인을 보고하고 기존 결과나 안전 기준을 임의로 바꾸지 않는다.

위 사례는 작업을 위한 목표이며 자동화된 시험이 이미 존재한다는 뜻이 아니다. 막다른 차로를 예외 없이 금지하는 법규로 간주하지 않는다.

## 완료 판정의 실무 기준

수용을 위한 제안이며 사용자 화면 승인을 대신하지 않는다. 각 대표 사례는 재현 가능한 입력, 결과, 기대값과 실제값, 실패 위치·이유, 미검증 항목, 화면 확인 상태를 함께 남긴다. 기존 여섯 사례와 사용자 A/B는 서로 다른 입력이다. A/B는 골든 기대값이 아니다.

- **동일 조건 비교:** 외곽·코어·기둥·램프와 대지·도로 입력의 동일 여부를 기록하고, 주차대수·진입과 진출·막다른 가지와 해당 칸·주차 이용 없는 공간을 함께 비교한다. 자동 DA/PIT 제안은 실제 설비 면적이 아니다.
- **순환과 차량:** 주 경로의 계산 결과, 각 가지 및 칸의 이용 가능성, 회차·교행·차량 크기별 확인 범위를 분리한다. 주 경로 clear나 단순 모형만으로 전체 차량 이용 가능을 선언하지 않는다.
- **도로와 입력:** 실제 입력이 없는 대지·도로는 미입력으로 표시한다. 외부 연결과 허가, 충돌 등 확인하지 않은 항목은 합격으로 표시하지 않는다. 저장과 재열기는 동일 입력·결과와 기존 장면 보존을 확인한다.
- **종료:** 공통 시험, 작업별 성공·반례, 필요한 독립 검토, 대표 화면에 대한 사용자 확인을 각각 충족해야 한다. 한 항목이라도 대기 또는 실패면 전체 완료가 아니다.

## 10월 31일 목표와 우선순위

## 순환 대안 첫 실험: 2026-10-28

사용자 B의 기존 외곽·코어·기둥 53개·램프를 고정하고, 기존 순환선의 두 지점을 잇는 직각 차로 5개 위치를 비교했다. 기준은 82대, 기존 주 경로 진입·진출 clear다. 결과는 84~89대였지만, 4개 위치는 연결 일부가 차로 면을 벗어나 막다른 끝이 생겼고, 나머지 한 위치는 기둥 2개가 새 차로와 겹쳤다. 두 후보는 연결 문제와 기둥 충돌이 함께 있었다. 따라서 수용 가능한 후보는 없었다.

이 결과는 이 다섯 위치의 직각 연결만 시험한 것이며 다른 구조의 순환안이 불가능하다는 뜻은 아니다. 램프 몸체와 교차하는 연결 및 고정 기둥 사이의 폭 확보가 다음 구조 검토의 핵심이다. 주 경로 clear는 새 연결 구간의 실제 주행, 칸별 입출차나 교행의 합격을 뜻하지 않는다. 상세 수치와 시험 범위는 `tools/harness/work-items/UG-LAYOUT-005.yaml`에 기록했다. 첫 시도에서 유효한 후보가 나오지 않아 10월 31일 전체 완성은 여전히 보장할 수 없다.
